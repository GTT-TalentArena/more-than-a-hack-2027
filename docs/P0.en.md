## What has been implemented

- An extension of the existing pipeline, without creating another evaluator.
- A configurable `modelo` mode: baseline, test constant and the module adapter from the A/B brief.
- Generation → official validation → public evaluation → comparison → record.
- Strict configuration, effective copy, commit, environment, declared seeds, hashes, split and duration.
- Exclusive folders, atomic writing of the record and locking of the shared index.
- Technical failures recorded; low metrics as a warning by default, with an optional explicit check.
- Reusable contract validators and tests without restricted data.
- A Compose `modelo` service and an extension of the existing Docker workflow.

The future football modules still need to implement their signals. The baseline is kept identical to the official one and does not implement P1/P2 by itself.
